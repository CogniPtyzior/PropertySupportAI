PropertySupport AI

GenAI workflow assistant for property support teams.

What it does

PropertySupport AI receives support requests, classifies them, retrieves context from SQLite, runs a LangGraph workflow and returns a sourced JSON response.

Workflow

FastAPI /ask
  → classify_request
  → extract_entities
  → route_intent
  → lookup | communication | ticket_workflow | incident_analysis | clarification
  → validate_response

Lookup

Answers factual questions from database context.

Communication

Drafts resident or provider messages.

Ticket workflow

Creates safe-mode ticket suggestions.

Incident analysis

Builds operational action plans.

Safe mode

Tickets are read-only. AI suggestions are stored in ticket_events and require human validation.
